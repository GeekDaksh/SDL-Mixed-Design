# standards/

Frozen primary sources.

This directory holds the primary standards documents the pipeline is built on — the IS PDFs
themselves. They are **frozen**: a file placed here is never edited, re-typeset, annotated or
re-exported. If a newer edition of a standard is adopted, it enters as a new file under its own
year, and the old file stays.

`MANIFEST.sha256` is generated by `scripts/00_freeze_standards.py`. It records the content hash of
every file in this directory at the moment it was frozen.

`s01_codify` refuses to load a PDF whose hash is absent from the manifest, and refuses to load one
whose hash no longer matches. A rule may only cite a source that was frozen; a clause read from an
unhashed document cannot enter the registry.

The PDFs are not committed (see `.gitignore`) — `MANIFEST.sha256` is what travels with the
repository, so any copy of the standards can be checked against the set the rules were codified
from.
